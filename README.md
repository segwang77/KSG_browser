# KSG

macOS 스타일의 데스크톱 화면(메뉴 막대 · 바탕화면 폴더 · 창 · Dock)을 가진 Windows용 브라우저입니다.
Electron(Chromium) 위에서 동작하며, 화면에 보이는 것은 모두 HTML/CSS로 직접 그립니다.

## 사용법

| 하고 싶은 일               | 방법                                                |
| -------------------------- | --------------------------------------------------- |
| 폴더 옮기기                | 바탕화면의 폴더를 끌어서 원하는 곳에 놓기           |
| 폴더 열기                  | 폴더 더블클릭 → 폴더 창이 열림                      |
| 주소로 이동                | 폴더 창 안의 주소를 더블클릭 → 브라우저 창에서 열림 |
| 주소 추가                  | 폴더 창의 `+` 버튼, 또는 브라우저의 ☆ 버튼(Ctrl+D)  |
| 주소를 다른 폴더로         | 주소를 끌어서 사이드바나 바탕화면의 폴더에 놓기     |
| 새 폴더 / 이름 변경 / 삭제 | 바탕화면이나 폴더에서 오른쪽 클릭                   |
| 창 닫기 / 최소화 / 확대    | 창 왼쪽 위의 빨강 / 노랑 / 초록 버튼                |
| 앱 종료                    | 메뉴 막대 왼쪽 끝 ⬡ → 종료 (Ctrl+Q 또는 Alt+F4)     |

### 단축키

| 키                        | 동작                          |
| ------------------------- | ----------------------------- |
| Ctrl+T / Ctrl+W           | 새 탭 / 탭 닫기               |
| Ctrl+Shift+T              | 닫은 탭 다시 열기             |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음 탭 / 이전 탭             |
| Ctrl+L                    | 주소창으로 이동               |
| Ctrl+R, F5                | 새로고침                      |
| Alt+← / Alt+→             | 뒤로 / 앞으로                 |
| Ctrl+N / Ctrl+Shift+N     | 새 창 / 새 프라이빗 창        |
| Ctrl+F                    | 페이지에서 찾기               |
| Ctrl+D                    | 책갈피 추가                   |
| Ctrl + `+` / `-` / `0`    | 확대 / 축소 / 실제 크기       |
| F11                       | 전체 화면                     |
| F12                       | 개발자 도구 (개발 모드에서만) |

## 파일 구조

| 파일                                          | 역할                                                   |
| --------------------------------------------- | ------------------------------------------------------ |
| `src/main.ts`                                 | 메인 프로세스: 창 생성, 보안 설정, 다운로드, 상태 저장 |
| `src/preload.ts`                              | UI와 메인 프로세스를 잇는 다리                         |
| `src/renderer.ts`                             | UI 시작점: 각 부분을 조립하고 단축키를 연결            |
| `src/index.css`                               | 전체 디자인. 맨 위 변수에서 색과 크기를 바꿀 수 있음   |
| `src/ui/wm.ts`                                | 창 관리자: 신호등 버튼, 창 이동, 크기 조절, 최소화     |
| `src/ui/desktop.ts`                           | 바탕화면과 폴더 아이콘                                 |
| `src/ui/finder.ts`                            | 폴더 창                                                |
| `src/ui/browser.ts`                           | 브라우저 창: 탭, 주소창, 웹뷰, 책갈피, 다운로드        |
| `src/ui/menubar.ts`, `dock.ts`, `settings.ts` | 메뉴 막대, Dock, 설정 창                               |
| `src/ui/store.ts`                             | 폴더 · 주소 · 방문 기록 · 설정 데이터                  |
| `src/shared/cursors.ts`                       | macOS 스타일 커서 그림                                 |

폴더와 주소, 방문 기록, 설정은 `%APPDATA%\KSG\state.json`에 저장됩니다.

## 알아둘 점

- 웹사이트의 위치 · 카메라 · 마이크 · 알림 권한 요청은 모두 거부하도록 되어 있습니다(`src/main.ts`의 `ALLOWED_PERMISSIONS`).
- 폰트는 Pretendard, 아이콘은 Lucide를 씁니다. Apple의 폰트 · 아이콘 · 배경화면은 포함하지 않았습니다.
